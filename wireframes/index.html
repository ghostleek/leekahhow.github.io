Key differences at a glance

AspectBeforeAfter (proposal)
Page weight~7.2 MB (2.8 MB bg photo, 2.6 MB icon fonts, ~113 KB jQuery + helpers)< 1 MB (compressed WebP photos, inline SVG icons, no jQuery)
NavigationJS hash-“modals”; no section URLs; keyboard-broken panelsSticky nav to real sections with shareable URL fragments
ContentBio + education table + 2 photos; much of it commented out or staleAbout timeline, project cards, gallery, revived data viz, working contact form
ThemingFixed dark theme, hard-coded colours in Sass variablesCSS custom properties; light/dark via prefers-color-scheme + manual toggle
AccessibilityNo focus management, user-scalable=no, div-as-dialog, no reduced-motion pathSemantic landmarks, focus-trapped menu, visible focus rings, prefers-reduced-motion
SEO / sharingNo meta description, OG cards, favicon, or structured dataFull meta + OG/Twitter cards, JSON-LD Person profile, sitemap, robots.txt
Tech stackjQuery + precompiled Sass, no build stepYour choice: plain HTML/vanilla JS (keep zero build), or Astro/Eleventy for a growing portfolio

How to decide

  1. Open both wireframes (above) and check the mobile views too.
  2. Pick a scope: A — full restructure (the whole “after”); B — light refresh (keep the modal layout, apply only the weight/SEO/accessibility fixes, ~2 days); C — not now.
  3. Tell me your scope + stack (vanilla vs Astro/Eleventy) and I’ll implement it in follow-up PRs, one phase at a time.

This PR is additive-only: it adds a wireframes/ folder and touches nothing else, so merging it can’t change the live site. Once merged you can preview these pages at leekahhow.com/wireframes/. The template’s CC-BY attribution is preserved in any redesign.
